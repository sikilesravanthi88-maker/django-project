# Django Student Project

A simple web application built using Django to manage student records.

## 🚀 Features
- Add new student details
- Update existing student information
- View student data

## 🛠 Tech Stack
- Python
- Django
- SQLite (default database)

## 📁 Project Structure
students_project/
│── students_app/
│── templates/
│── manage.py

## ▶️ How to Run
1. Clone the repository
2. Navigate to project folder
3. Run:
   python manage.py runserver
4. Open browser and go to:
   http://127.0.0.1:8000/
